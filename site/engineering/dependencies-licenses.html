研发工程与演进

依赖矩阵与许可合规

区分自有私有 ROS 2 包、隔离模型工作容器、前端底座与外部固定快照

本页汇总项目各子系统在 package.xml、pyproject.toml、package.json 及 requirements*.txt 中明确声明的依赖版本与许可归属。第一方自研代码维持私有许可，第三方向组件遵循各自原开源协议；公开文档站点不随站分发设备专有 SDK、神经网络权重二进制、大型仿真网格或录包资产。

一、第一方私有软件包的模块与协议边界

根据各模块 package.xml 清单，6 个核心 ROS 2 软件包的名称、版本与构建系统如下：

包名与清单路径 版本与构建方式 声明许可与核心编译依赖
embodied_core（src/embodied_core/package.xml） 0.1.0 · ament_python Proprietary；运行依赖 python3-yaml
embodied_interfaces（src/embodied_interfaces/package.xml） 0.1.0 · ament_cmake Proprietary；编译 rosidl_default_generators，依赖 geometry_msgs、sensor_msgs，定义 84 份 IDL（56 msg / 22 srv / 6 action）
embodiment_runtime（src/embodiment_runtime/package.xml） 0.1.0 · ament_python Proprietary；依赖 embodied_core、python3-yaml
facility_hal（src/facility_hal/package.xml） 0.1.0 · ament_python Proprietary；场景无关设施 HAL 与 HTTP/1.1 网关，依赖 embodied_core、python3-yaml
robot_app（src/robot_app/package.xml） 0.1.0 · ament_python + C++20 Makefile Proprietary；依赖 embodied_core、embodiment_runtime、embodied_interfaces、rclpy、sensor_msgs、geometry_msgs、tf2_ros、action_msgs、message_filters、ament_index_python
system_app（src/system_app/package.xml） 0.1.0 · ament_python Proprietary；依赖 embodied_core、embodied_interfaces、rclpy、python3-yaml、python3-jsonschema、python3-jieba、ament_index_python

二、Python、模型服务与前端生态系统版本基线

仓库按运行时职责拆分为独立 Python 环境与浏览器前端工程，严禁跨容器混装二进制扩展（例如不得混用宿主机 Python 与模型容器中带的 CUDA/PyTorch 编译库）：

子系统与清单位置 运行定位 已验证声明依赖及固定版本
控制台服务端 embodied-hybrid（apps/collaboration_platform/pyproject.toml） 只读车队观测、实机/仿真回放与 hybridctl CLI Python >=3.10、fastapi >=0.115,<1、uvicorn >=0.30,<1、websockets >=13,<16、httpx >=0.27,<1；可选 navigation-overview: ir-sim ==2.12.0；开发 pytest >=8,<9
前端三维控制台 embodied-hybrid-console（apps/collaboration_platform/web/package.json） :18640 Three.js 视口、节点图编排与时序曲线 react ^19.1.0、react-dom ^19.1.0、three 0.186.1、@xyflow/react ^12.8.0、uplot ^1.6.32、urdf-loader 0.13.1、meshoptimizer 1.1.1、@dagrejs/dagre ^1.1.5、lucide-react ^0.468.0、@soundtouchjs/core 2.1.1、typescript ^5.8.3、vite ^6.3.5
模型统一网关 embodied-model-gateway（apps/model_gateway/pyproject.toml、requirements-gateway.txt） 回环鉴权 HTTP 接口与独立音视频工作者进程编排 fastapi >=0.100,<1、httpx >=0.27,<1、jsonschema >=4,<5、uvicorn >=0.30,<1、websockets >=14,<17、Pillow >=10,<13
语音与对话模型容器（apps/model_gateway/worker_services/requirements.txt） talk-system GPU 容器内 LLM / ASR / TTS 三推理服务 基础镜像 nvcr.io/nvidia/pytorch:25.08-py3（自带 torch 2.11 / CUDA / cuDNN）、vllm ==0.25.1、transformers ==5.14.1、fastapi ==0.136.3、uvicorn ==0.51.0、Pillow >=10.0 及同目录 vllm-omni 可编辑包
仿真与导航工具链（tools/navigation_irsim/requirements.txt、tools/navigation_visualization/requirements.txt） 二维激光仿真校验与三维调试预览工具 ir-sim ==2.12.0、numpy <2、tornado >=6,<7、viser ==1.0.30

三、外部模型权重、底层 C++ 库与离线哈希核验

  • 视觉与感知权重修订锁定：
    • nvidia/LocateAnything-3B 固定修订 c32291ca5e996f5a7a485845b4f57a233936bba0。
    • xiaomi Lens 固定修订 68f57cdde1a19f751e78b18af04efa8ca8bd7fce（源仓库锁定提交 9ecbee757b5b807a485845aeed44ed8cfec10bae）。
    • 工件 YOLOv8-seg + FoundationPose 原生管线沿用贡献源码包（Apache 2.0，见 src/robot_app/modules/perception_runtime/README.md）与 v0.1.0 ONNX 发布校验 8d749f9e5953054432201450f724368243b4e16b2441042db766df306ae2433b。
  • 对讲语音与多模态服务权重：Qwen--Qwen3.8-27B-FP8（端口 9527）、Qwen3-ASR-0.6B（端口 9528）与 Qwen3-TTS-12Hz-0.6B-CustomVoice（端口 9529）。
  • C++20 底层算法编译库：tools/deployment/build_pct_sdk.sh 从静态源码构建 gtsam-4.1.1 与 osqp，原生多进程核心采用纯 g++ -std=c++20 -pthread -ldl -lm 无额外强耦合容器框架依赖，可在运行时按需 dlopen 加载 onnxruntime。
  • 离线校验入口与声明留存：全部平铺进入仓库 thirdparty/ 的源码目录及补丁均记录于 docs/manifests/upstreams.json、docs/upstreams.json、docs/vendor-files.json 与 THIRD_PARTY_NOTICES.md，可通过 python3 scripts/verify_sources.py 离线核对全部文件与补丁 SHA-256。对于改造过的第三方适配器（如设备通信或局部规划修正），均保留原始仓库 URL、修改说明与版本号，不将魔改版本混标为上游原版。
