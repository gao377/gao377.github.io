A

职责与公共能力

SW-12 → RB-01。空间模块拥有度量定位、地图产物及其版本。 本体状态提供关节相关TF，传感适配提供激光与IMU。导航消费空间结果；图像目标识别仍由感知模块负责。

公共能力 会话语义 实现出口
spatial.build_map 启动后持续建图，显式finalize保存 OnlineMapping→MapRef
spatial.localize 加载已校验地图，持续报告定位质量 LocalizationNode→SpatialPoseTracker
spatial.relocalize 现有定位会话内重新检索与注册 ScanContext→ICP→重启定位→新反馈确认

G1装配注册这些provider。就绪查询只校验原生程序、配置及输出路径，不启动进程。 运行仍需真实传感、有效地图和新鲜质量反馈。离线建图工具与在线公共能力不是同一入口。

B

组件和坐标数据流

原生Lightning消息的 lidar_link 标签不直接等于机器人base。桥接明确解释其IMU数值语义，再使用同戳URDF关节TF组合。不要直接复制原生消息作为本体位姿。

本体速度采用同一扫描末端时间戳。躯干IMU以50Hz采样，采样时刻与扫描末端不必重合。桥接对相邻真实角速度样本做线性插值，再计算IMU到base的杠杆臂速度修正。

采样间隔须在既有40ms关联界内。缺下一帧时仅有限排队，不外推、不补零、不重写扫描时间戳。地图版本变化或时钟回跳清除排队数据。原始localization/pose、localization/odom和locate()保持实测定位语义。

导航专用参考由GaitPoseFilter生成。SIM profile采用10Hz源、单节1.3Hz/Q=3因果SciPy陷波，对x/y/z和展开yaw递推。当前模式为shadow：输出可观测，导航控制仍用原输入。map→nav_stabilized是虚拟叶子，roll/pitch置零表示重力对齐投影，不能解释为IMU估计精度提升。

NavigationFrame保留原/平滑位姿、同戳T_SB、epoch、地图版本、质量与滤波身份。spatial.navigation_frame(stamp_ns=None)读取当前快照或历史关联。重复stamp不重滤；缺帧、质量恢复、地图版本变化或时钟回退重新预热2s。WARMING/INVALID均不代表控制就绪。断帧不补样，源年龄保持原含义。

短历史最多10s/200样本。平移和SciPy Slerp只在相邻已观测、有效且同epoch的样本间插值；不使用最新位姿配旧图像，也不外推。transform_cloud和transform_goal把固定map几何转到同一S系；反变换后世界点和目标仍固定。raw_to_smooth只是几何残差，不是运动预测。

新增ROS出口为/robots/<robot_id>/spatial/navigation/{pose,odom,debug}。pose/odom的父系是map，odom子系为nav_stabilized；twist来自平滑源位姿有限差分并表达在S，不复制SDK速度。首样本或断帧的twist标为无效。原TF出口拥有新叶子，没有另一个节点改写base_link。

参数位于configs/spatial/g1_navigation_frame_sim.yaml。当前资格来自SIM离线源时间回放，不是新导航或REAL控制验收。本体停稳和操作仍使用STATE/BODY的实际关节、IMU与本体局部坐标。

C

在线建图状态视图

close()先阻止新请求，等待保存或原生重启结束，再停止捕获的会话。 保存中取消不会注册MapRef。Robot关闭时先收尾空间模块，最后关闭本体SDK。

mapping_ready表示可消费建图定位。map_saved只在产物、索引和版本生成后成立。启动进程或收到第一条odom均不能代替这两个条件。

D

重定位时序

候选检索失败或ICP不通过时拒绝恢复。重启前的排队消息不能用于确认。重定位不获得运动租约，也不主动移动机器人。

E

算法与参数入口

组成 采用实现 配置或边界
激光惯性建图 模块内Lightning原生快照 固定外参与逐点采样时间
地图定位 Lightning原生匹配质量 NDT_MATCH等有效匹配来源
地点检索与注册 ScanContext与强制ICP 禁止registration=none
本体位姿转换 既有FrameStore与TF组合 map→IMU→pelvis→base
导航专用平滑参考 SciPy iirnotch/sosfilt及Slerp 因果、同戳、当前shadow；原定位不被覆盖
版本与产物 hashlib、PCL读写、关键帧检查 MapRef身份与内容一致

SpatialPoseTracker的默认位姿年龄为0.5s，质量年龄为1s。导航还可对自身输入施加更短年龄要求。地图保存等待上限60s。超时后TERM等待5s，仍未退出则KILL并回收。 离线工具默认执行上限600s。

SIM初始化profile用50Hz IMU、2s窗口、100帧。外参、重力参数和静止统计阈值保留在profile，不复制为其他本体的默认值。

探索会话在收臂后以新鲜原生注册云记录home局部锚点。 Open3D原生point-to-plane ICP使用Tukey核，计算当前本体与锚点的局部关系。 质量要求fitness不小于0.6、点到平面RMSE不超过4cm。点到点RMSE单独报告。 原生全分辨率云是可选出口，不改变导航原有降采样点云。两路使用同一源时间戳。

锚点有效期0.2s；过期、回跳或地图版本变化不产生假新鲜结果。 当前锚点为会话内对象。保存后依据优化关键帧重建锚点的能力另行验证。

F

地图内容与用途边界

离线导航振荡分析

scripts/analyze_g1_navigation_gait.py 使用ROS原生压缩录包解码器、SciPy Welch/coherence及因果SOS陷波回放，分析定位、躯干IMU、下肢关节及TF的源时间。接收时间只用于消息排序，不当作机器人运动时间。

在已安装ROS与SciPy的机器人运行环境执行。输出目录必须不存在，原录包只读。qualification.json记录采样间隔、频谱、候选增益和延迟；series.npz支持后续用--series分析而不重复解码。缺帧按原时间重置，因果回放不能读取未来样本。停稳窗口来自实际发令和BODY反馈，不使用仿真真值。

该工具不发布控制命令。离线滤波资格不等于导航闭环或实机验收；配置接入运行链后仍需独立验证刹停、精调和返航。短窗口频谱不能代替充分的站立或转弯实验。

产物 用途
global.pcd、分块PCD、index.txt 原生地图加载
keyframes.csv 优化后的关键帧位姿
keyframe_clouds、frame元数据 本体局部查询云与索引对齐
scancontext.npz 重定位候选检索
profile.yaml、内容哈希 外参、来源与版本一致性

当前公共保存链生成Lightning地图包。二维PGM/YAML导出、地图标注和结构化空间记忆不属于该保存实现。后续二维地图由空间模块提供，人工语义由系统记忆模块拥有。

地图锚点保存关键帧ID及相对位姿，重建时使用优化关键帧。不能将一次建图时的绝对坐标直接视为永久空间记忆。

H

验证方法

分别核查逐点时间、IMU外参、腰部动态TF、map版本、匹配质量和保存产物。重定位需验证候选、ICP以及重启后的新反馈。

地图文件结构通过，不代表定位精度或探索覆盖率通过。复验时绑定机器人模型、传感profile、原生版本和场景，保留失败来源。
