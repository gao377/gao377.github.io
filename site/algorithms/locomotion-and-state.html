下肢策略与状态估计

FacriMjlabPolicy 推理链、斜率限幅、防倾覆抑制与 IMU 判稳门禁

定位与上下游边界

下肢运动控制与状态估计运行于端侧 P0 实时进程（robot_body_rt）与本体后端适配器之间：上游消费经时间戳同步的 IMU、29 自由度关节角速反馈以及 100 ms 内有效的上肢参考量，下游向 SAL / HAL 输出受斜率限幅与倾角抑制保护的双足关节目标，同时向上层 manipulation_runtime 提供 BodyStabilityMonitor 躯干停稳门禁信号。完整 4+1 进程隔离部署见 单机 C++20 4+1 多进程实时架构。

一、下肢强化学习策略推理：FacriMjlabPolicy 与 PolicyRunner

FACRI 在 Python 后端与 C++20 实时控制进程中提供同一语义的策略执行路径：

  1. Python SIM 专用策略封装（src/robot_app/backends/facri/mjlab_policy.py）：FacriMjlabPolicy 将 47 维单帧观测映射为 12 维腿部关节绝对位置指令，仿真步长 simulation_dt = 0.005 s、抽样倍率 control_decimation = 4（控制周期 period_ns = 20_000_000，即 50 Hz），标准步态相位周期为 0.8 s。
  2. 模型身份与硬件隔离：加载阶段强制对 policy.onnx 与 YAML 配置执行 SHA-256 哈希核验；且严格限制 origin == 'SIM'，若在 REAL 实机上调用会直接抛出 FACRI_MJLAB_REAL_NOT_QUALIFIED 拒绝运行。
  3. 输出尺度映射与门控：通过 action_scale = 0.25 * effort_limits / kp 计算增量并叠加名义关节角 q_abs = nominal + action_scale * action；支持 legacy_xy_v1 与 command_norm_v1 两种静止门控模式，并在 urdf_limits 启用时将指令截断在物理关节限位内。
  4. C++20 常驻推理内核（src/robot_app/algorithms/policy_infer/policy_runner.hpp）：PolicyRunner 与 ObservationEncoder 运行在实时进程 robot_body_rt 内，维护 kPolicyJointCount = 29（kLegDofs = 12 与 kUpperDofs = 17）及 kHistoryLength = 10 × kFrameObsDim = 100 = kTotalObsDim = 1000 维历史矩阵，并核验上肢参考数据时效 kUpperRefMaxAgeNs = 100 ms。优先通过 dlopen 调用 onnxruntime，若无加速库则回落至内置 OnnxProtobufMlp 或固定确定性核，并配合 SimPositionExcursionGuard（连续超差 100 ms 触发保护）防止关节失控漂移。
[IMU / 29 关节角速反馈 + 100 ms 上肢参考]
          │
          ▼  (ObservationEncoder: 10 x 100 = 1000 维 / 或 FacriMjlabPolicy: 47 维)
[PolicyRunner (ONNX Runtime / Built-in MLP) @ 50 Hz]
          │  action_scale = 0.25 * effort_limits / kp
          ▼
[q_abs 目标 + 双向速度斜率限幅 + 倾角抑制器] ──► [SAL / HAL 写入 29 关节]

二、速度准入、双向斜率控制与防倾覆抑制

在 src/robot_app/backends/facri/app_body.py、bound_control.py 与 control_cycle.py 中，FacriBodyBackend 对上层导航或操作下发的速度指令 (vx, vy, vyaw) 执行三级动力学防护，避免高惯量步态瞬间切换诱发跌倒：

机制模块 源码位置 关键参数与阈值 工程物理含义
速度指令上限准入 command_admission 最大容许 (0.85, 0.20, 0.40) m/s、m/s、rad/s；默认 (0.2, 0.1, 0.3) 约束横移与偏航幅度，防止单周期步幅超出支撑多边形
SIM 双向斜率限幅器（_slew_sim_velocity） src/robot_app/backends/facri/bound_control.py SIM_ACCEL_LINEAR_STEP_MPS = 0.022、SIM_DECEL_LINEAR_STEP_MPS = 0.06、SIM_DECEL_GATE_SNAP_MPS = 0.055、SIM_ACCEL_YAW_STEP_RPS = 0.04、SIM_DECEL_YAW_STEP_RPS = 0.08 加速慢（每周期 0.022 m/s）、减速快（每周期 0.06 m/s），并在接近停止阈值 0.055 m/s 时果断归零锁定，抑制踝俯仰停止振荡

实测限幅与四周期温和回退 check_measured_limits SIM_VELOCITY_RECOIL_TICKS = 4，比例系数 2.5 仿真下肢由强化学习策略轴承担跟随故跳过下肢静态位置报警；当发生速度越界或短暂失稳时执行 4 个周期温和反冲制动

需要指出，配置文件 src/robot_app/backends/facri/control_config.py 同时关联了经审阅的原生站立测试档 N02 与 N03_DIAGNOSTIC_SIM_ONLY（验证覆盖 4 组 × 6000 步），该组仅用于下肢站立诊断对照，不代表完整应用任务资格。

三、多模态状态估计与躯干静止判稳

状态估计模块在 src/robot_app/modules/state_estimation/domain.cpp 与 src/robot_app/modules/state_estimation/domain/stability.py 中统一聚合高频传感器观测，向操作与导航层提供唯一权威坐标系：

  1. IMU 去偏斜与 17 自由度上身 FK：StateEstimationDomain 使用时间戳对 IMU 角速度与加速度缓存执行插值匹配，结合 17 自由度上身运动学正解（FK）计算整机质心（CoM）偏移与躯干姿态角。
  2. 静止判稳窗口门禁（BodyStabilityMonitor）：双臂开始操作或交接前必须确认本体停稳。判稳条件在滑窗 window_s = 1.0 s 内连续检查三项约束：最近采样延迟不超过 MAX_AGE_NS = 40 ms、相邻采样时间间隔不超过 max_gap_ns = 80 ms、躯干倾斜总角不超过 10°，且当前下发期望速度必须处于零速带（<= 1e-5）并保证 epoch 与 stamp_ns 严格单调递增。
