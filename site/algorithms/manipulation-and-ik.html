双臂规划与柔顺操作

49 候选阻尼最小二乘 IK、连续 Minkowski 扫掠碰撞与纯接触导纳

上身操作模块运行在零 <weld> 辅助的纯物理接触基准上，需要同时协调双 7 自由度机械臂与 3 自由度腰部共 17 个上身自由度，在狭小工装与设备按钮前方完成轨迹生成、连续碰撞核验及力控触底放置。运行边界与全局冻结参数见 运行基线与冻结配置，仿真接触机制见 MuJoCo 4.0.1 仿真引擎。

一、17 自由度上身规划与 49 候选阻尼最小二乘 IK

UpperBodyPlanner 与 DlsIkSolver（src/robot_app/algorithms/planning_core/upper_body_planner.hpp、upper_body_planner.cpp 与 dls_ik_solver.hpp）负责双臂及腰部统一逆运动学求解：

  1. 关节分工与腰部刚度加权：规划向量维度 kUpperBodyDofs = 17（左右双臂各 7 轴，加上腰部偏航 yaw ±40°、俯仰 pitch [-10°, +30°]、横滚 roll ±25° 三个硬约束关节）。DlsIkSolver 采用阻尼参数 ik_damping = 0.015、单点最大迭代 48 次与分段末端误差上限 max_segment_pos_err_m = 0.020 m；腰部三轴权重差异显著设置（yaw = 1.0、pitch = 10.0、roll = 100.0），优先由双臂与腰部偏航消化大角度工作空间需求，严密抑制容易危及双足平衡的躯干侧倾。
  2. 49 候选分级邻域搜索（plan_cartesian_49）：当标准中心点（(0, 0)）无法避障或触达运动学奇异区时，规划器在笛卡尔横向平面沿 ±30 mm 网格展开尝试，依「中心 (0, 0) → 单臂小幅偏置 → 双臂组合 7×7 = 49 组」顺序快速检索可行无奇异通道，并在固定时间格（20 ms 步长最小加加速度插值，最多 kMaxTcpSegments = 100 段）上生成共线同步的时间序列。
  3. 持物双臂中点约束与轻量按钮回退：搬运工况调用 compute_held_dual_tcp_targets 保持双夹爪相对工件中点刚性几何及最小连线旋转，配合每阶段触发的 2 cm / 3° 单次漂移纠偏与 kHoldingLeaseMaxDriftM = 0.050 持物租赁超时护栏；按钮点按完成返回时，ManipulationDomain（src/robot_app/modules/manipulation_runtime/domain.cpp）支持 kNone、kScalarActuator1D、kPrismaticLift1D、kDualArmTorsoIk 四类工作模式，并在按钮撤回启用 REVERSE_PREFIX_REPLAY（mode = 2）直接逆序回放已验证安全路径而无需重新规划。

二、种子插值与连续扫掠碰撞核验

模块 实现文件 核心技术细节
速度连续种子插值（seed.py） src/robot_app/modules/manipulation_runtime/domain/trajectory/seed.py 引入分段三次埃尔米特插值（CubicHermiteSpline），严格保留 TOTG 时间最优轨迹节点处的一阶速度连续性，取代容易在节点处引起电机力矩尖峰的常规线性插值
扫掠体积碰撞核验（DeviceCollisionQuery） src/robot_app/modules/manipulation_runtime/infrastructure/native_bindings/device_collision.py 基于连杆凸包与胶囊几何构建相邻离散构型间的 Minkowski 凸包扫掠体，依据 Bernstein 导数速度上界自动计算最大采样区间并执行自适应中点二分细分，防止高速轨迹「穿墙越过」窄小障碍边沿
原生输入合约（native_full_inputs.py） src/robot_app/modules/manipulation_runtime/domain/trajectory/native_full_inputs.py 校验双臂关节位置限幅、支持面边界与场景障碍几何版本一致性，缺项直接显式阻断执行

三、力矩观测、TouchdownGuard 与纯接触任务柔顺控制

在无桌面真值或 <weld> 外挂吸附的前提下，操作安全依赖于 src/robot_app/modules/manipulation_runtime/domain/control/wrench_observer.py（WrenchObserver）与 admittance.py（TaskAdmittanceSession / TouchdownGuard）共同提供的末端物理力感知：

  1. 纯臂关节雅可比滤波观测（WrenchObserver）：构造显式排除腰部关节的纯 7 自由度臂 Pinocchio 雅可比矩阵，使用解耦 3×7 线速度正则阻尼（lambda = 0.08）与剩余角速度正则阻尼（lambda = 0.35）反演末端接触六维力/力矩；滤除小于 deadband = 0.12 Nm 的关节微震并应用平滑系数 ema_alpha = 0.22；针对 SIM 无质量上肢配置显式置零重力项。
  2. 四套分阶段导纳控制剖面（TaskAdmittanceSession）：
    • FREE_GRAZE_COMPLIANCE_PROFILE：空手逼近及预备区防擦碰。
    • PICK_SEAT_COMPLIANCE_PROFILE：夹爪合拢贴紧工件端面。
    • HELD_TRANSPORT_COMPLIANCE_PROFILE：携物移动期间吸收双臂与腰部轻微内力拉扯。
    • PLACE_TOUCHDOWN_PROFILE：工装放置落地阶段顺应桌面倾角误差。
  3. 垂直触底判稳守卫（TouchdownGuard）：下降安置过程中激活小步距虚拟微探（下探 0.008 m，速率 0.015 m/s），实时监测竖直向上接触反力；仅当连续满足 fz >= 0.90 N 且平稳驻留 0.08 s 后才判定可靠着台并下发双爪释放指令，防止空中过早松爪导致工件跌落倾翻。
