五级验证阶梯与实证样本

从静态检查、纯接触 510/510 基准、SIT-F3 四机联调到诚实记录 R4 V0 FAIL 至 V1 PASS

本项目拒绝将单元测试通过、零物理动画演示或历史机型的局部成功混合包装为「全系统验收通过」。所有技术声称必须标注其在五级验证阶梯中的确切位置、样本编号、输入源边界及不可越界推广的范围。系统层 RSI 演化逻辑见 SystemAgent 与受控演化。

一、五级验证阶梯（L0 – L4）与反外推原则

层级 名称与验证工具 覆盖范围与典型指标 明确排除（不可外推结论）
L0 静态契约、架构与文档检查（check_docs.py、check_architecture.py、verify_sources.py） 校验 28 篇文档格式、模块所有权依赖方向及第三方资产 SHA-256 指纹 不运行任何 Python/C++ 业务逻辑、ROS 通讯或物理求解
L1 离线原语与纯接触网格单元回归（make test、pytest tests/unit、test_mujoco4_native_contact_fleet.py） C++20 分配器/IPC/解耦 3 套二进制测试；MuJoCo 4.0.1 接触对与排除规则测试 使用注入数据源或静态 XML 测试集，不证明连续多工位生产时序可行

L4 实机联调与真机端到端验收（facrictl start --real、FastDDS Domain 126） 真实相机、ZED 2i、实体传感器与实机执行器在受控安全边界内运行 需要每台本体独立标定与安全员现场监管；任何其它机种通过均不可跨机继承

二、权威量化基准：510 / 510 纯接触操演与 SIT-F3 四机联调

2.1 CAD 实体碰撞与 MuJoCo 4.0.1 纯接触操作验证（510 / 510）

依据 docs/verification/2026-11-20-mujoco4-cad-real-collision-manipulation.md 权威记录，纯接触操作栈在取消全部 <weld> 辅助锁定后取得 510 / 510（100.0%）全通过成绩：

  1. 离线扫描体积与 CAD 网格碰撞审计：对 589,400 次 COAL 几何碰撞样本与 151,538 帧运动学正解构型进行全量复核，非预期几何穿插数为 0。
  2. MuJoCo 4.0.1 第 2–4 阶段连续物理执行：合并 70 / 70 调试样本与 440 / 440 验证样本，覆盖 204 / 204 次按键按压、153 / 153 次双臂取料（pick）及 153 / 153 次柔性触底安置（place）。累计执行 859,974 个控制物理 tick（6,879,792 个 0.625 ms 物理子步），指端最大实测速率 0.15716 m/s <= 0.20 m/s（零超速违规），连续 1.25 s 无外力支撑自由悬停滑移跌落 <= 0.0020 mm。

2.2 四机多进程 C++20 工厂封闭回路集成测试（SIT-F3）

tests/integration/test_factory_4robot_multiprocess_closed_loop.py 拉起 robot_r1 至 robot_r4 四套真实 4+1 进程栈验证跨机工厂作业秩序：

  • 连续跑通 16 个工位完整作业循环、12 次 coordination.auto_task 自动接管覆盖及 6 对 coordination_dispatch_reserved / coordination_synchronized 同步日志事件。
  • 在 robot_r3 首轮任务中主动注入故障隔离校验（trigger_r3_deadman_brake_check），验证单机急停隔离不拖垮其余三台产线进程。
  • 全程审计 StarFleetBusState.get_agent_contracts() 自注册契约与每台机器人 3 次 manipulation.pick、3 次 manipulation.place 的 holding_context_ref 持物守恒性；SIGTERM 退场全部返回 rc == 0 且零孤儿残留进程。
